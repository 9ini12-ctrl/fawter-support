البيانات على جهازك

لا يرسل التطبيق بياناتك أو فواتيرك إلى خوادم المطوّر، ولا يتضمن إعلانات أو تتبعًا أو تحليلات. لا يتطلب إنشاء حساب.

تُحفظ بيانات المستقل واسم الجهة والوثيقة والتواصل والآيبان وبنود الخدمات والمبالغ وحالة السداد محليًا على جهازك. وقد تدخل هذه الملفات في النسخ الاحتياطية للجهاز وفق إعدادات Apple لديك.

مشاركة الفواتير

عند اختيار مشاركة PDF، تُدرج البيانات التي أدخلتها في ملف الفاتورة وتُرسل إلى التطبيق أو الجهة التي تختارها بنفسك. تخضع معالجة المستلم للبيانات لسياساته.

الحذف والتحكم

يمكنك تعديل بيانات المستقل وحذف الفواتير من التطبيق. إزالة التطبيق تحذف بياناته المحلية، وقد تبقى نسخ PDF المصدرة أو نسخ الجهاز الاحتياطية خارج التطبيق.

الأذونات والخدمات

لا يطلب فوتر موقعك أو جهات اتصالك أو الكاميرا ولا يتصل بجهات حكومية. لا يجمع المطوّر معلومات مالية أو شخصية عبر التطبيق.

هذه الصفحات وطلبات الدعم

تُستضاف صفحات الدعم لدى GitHub Pages، وقد تعالج GitHub سجلات الاتصال وفق سياسة خصوصيتها. إذا فتحت طلب دعم على GitHub، تظهر المعلومات التي تنشرها في الطلب للعامة؛ لا تضع وثائق أو فواتير أو بيانات شخصية حساسة.

التواصل

لأسئلة الخصوصية، افتح طلبًا للدعم دون إرفاق بيانات حساسة.
